## 遇到的问题

1. 模板里把 `|date` 写成了 `|data`，Django 报 `Invalid filter: 'data'`。
2. `posst` 拼写错误，导致摘要不显示。
3. `post_list` 视图误用了 `post_detail.html`，首页拿错了模板。
4. `{% if %}` 没有闭合，导致 `{% empty %}` 报错；`{ % url %}` 中间多空格也不会被识别。
5. 测试失败不一定是视图错：测试数据写的是“博客的1第一页”“这是详情正文”，断言写的是“博客的第一页”“这是详情页正文”，字符串不一致。
6. `git log --online` 是拼写错误，正确是 `--oneline`。
7. `runserver` 会占用终端，Git 命令要到另一个终端执行。

## 今天学到

- URL → View → Template 的完整请求链。
- `get_object_or_404` 找不到对象时抛出 `Http404`。
- `ForeignKey` 用 `select_related`，`ManyToManyField` 用 `prefetch_related`。
- `F("views") + 1` 让数据库原子递增，避免并发覆盖。
- Django 模板的 `for/empty`、`if/endif` 必须正确配对。
- 测试失败先看“期望值 vs 实际响应”，可能只是测试数据不一致。
- Git 提交存在 `.git` 里，和终端窗口开没开无关。
