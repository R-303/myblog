## 遇到的问题

### 1. 生产环境变量模板被 Git 忽略

`.gitignore` 里有：

```text
.env.*
!.env.example
```

因此 `.env.production.example` 也被忽略了，`git add` 拒绝添加。

修复：

```text
!.env.production.example
```

以后真正的 `.env` 仍然不会被提交，只有模板会进入仓库。

### 2. 环境变量名拼写错误

模板里曾写成：

```env
DJANGO_SECRET_KET=...
```

正确是：

```env
DJANGO_SECRET_KEY=...
```

这种错误不会在本地立刻报错，但生产环境会读不到密钥。

### 3. Actions 页面看起来只有一项

GitHub Actions 列表里一行代表一次 **workflow run**，不是单个 job。

点进 `CI #3` 后可以看到：

```text
test   ✅
docker ✅
```
