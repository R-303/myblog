## 遇到的问题

### 1. 注册表单字段大小写错误

报错：

```text
django.core.exceptions.FieldError: Unknown field(s) (Username) specified for User
```

原因是 `UserRegistrationForm.Meta.fields` 里写成了大写的 `Username`：

```python
fields = ["Username", "email"]
```

而 Django 用户模型里的字段名是小写的 `username`。Python 字段名区分大小写。

改成：

```python
fields = ["username", "email"]
```

### 2. 搜索测试的标题字符串不一致

搜索本身正常，响应里已经出现“Django 搜索测试”，但测试断言失败：

```text
Couldn't find '搜索: Django'
```

页面实际标题是：

```text
搜索： Django
```

差异在冒号：

- 英文冒号 `:`
- 中文冒号 `：`

中间还一度写成了两个冒号：

```text
搜索:：Django
```

最终把视图和测试统一为中文冒号加空格：

```text
搜索： Django
```

## 今天学到

- Django 的 `UserCreationForm` 已经封装了密码校验、密码哈希和两次密码确认。
- `Meta.fields` 里的字段名必须和模型字段完全一致，包括大小写。
- `FieldError: Unknown field(s)` 先看错误里列出的字段，再和模型定义对照。
- `LogoutView` 只接受 POST，模板里必须使用带 CSRF token 的表单。
- `Q` 对象可以组合多个 OR 条件，适合简单的多字段搜索。
- `icontains` 是 SQL 层面的模糊匹配，不是真正的全文索引。
- `aggregate()` + `Count()` + `Sum()` 可以一次得到后台统计数据。
- `assertContains` 是精确子串匹配，中文标点、空格和大小写都会影响结果。
- 搜索功能是否成功，要先看响应里有没有文章；标题断言失败不一定是搜索逻辑失败。
