## 遇到的问题

注册表单初始化时报错：

```text
django.core.exceptions.FieldError: Unknown field(s) (Username) specified for User
```

原因是 `UserRegistrationForm.Meta.fields` 里写成了大写的 `Username`：

```python
fields = ["Username", "email"]
```

而 Django 用户模型里的字段名是小写的 `username`。Python 字段名区分大小写，所以 Django 找不到 `Username` 这个字段。

改成：

```python
fields = ["username", "email"]
```

## 今天学到

- Django 的 `UserCreationForm` 已经封装了密码校验、密码哈希和两次密码确认。
- `Meta.fields` 里的字段名必须和模型字段完全一致，包括大小写。
- `FieldError: Unknown field(s)` 先去看错误里列出的字段，再和模型定义对照。
- `login()` 可以显式指定 `ModelBackend`，避免以后有多个认证后端时产生歧义。
- `LogoutView` 只接受 POST，模板里必须用带 CSRF token 的表单。
- `user.is_authenticated` 可以用来在模板里切换登录/未登录状态。
- 认证回答“你是谁”，授权回答“你能做什么”，这一阶段先完成认证。
