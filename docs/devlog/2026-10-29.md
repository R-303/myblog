## 今天的目标

在已上线的博客上增加一个临时的“私密站点”模式：

- 隐藏注册入口；
- 关闭公开注册；
- 未登录访问网站时先跳转登录页；
- 只有预先创建的账号可以访问；
- 以后可以通过配置恢复公开访问。

本阶段暂不优化 CSS，只做访问控制和必要的最小模板调整。

## 需求设计

### 私密访问

- 新增 `PRIVATE_SITE` 环境开关；
- 未登录访问首页、文章、分类、标签、归档、搜索等页面时，跳转到 `/account/login/`；
- 登录成功后回到原地址；
- `/healthz/` 保持匿名可访问，便于健康检查；
- `/admin/` 保留 Django 后台自己的登录逻辑。

### 关闭注册

- 新增 `ALLOW_REGISTRATION` 环境开关；
- 关闭时不在导航栏显示“注册”；
- 直接访问注册地址也不能创建账号；
- 朋友账号由管理员在后台或 Django shell 中创建；
- 普通用户不给 staff/superuser 权限。

### 后续恢复公开

以后只需要在服务器 `.env` 中修改：

```env
PRIVATE_SITE=false
ALLOW_REGISTRATION=true
```

不需要重新改模板和中间件逻辑。

## 提交前发现的问题

### 1. `startswith` 拼写错误

`blog/middleware.py` 当前写的是：

```python
request.path.startwith(prefix)
```

正确应为：

```python
request.path.startswith(prefix)
```

否则只要有请求经过中间件，就会报 `AttributeError`。

### 2. 注册关闭判断位置错误

`blog/views.py` 中：

```python
if not settings.ALLOW_REGISTRATION:
    raise Http404
```

被放在了 `return render(...)` 之后，代码永远不会执行到。

应放到 `register()` 函数最前面：

```python
def register(request):
    if not settings.ALLOW_REGISTRATION:
        raise Http404

    if request.user.is_authenticated:
        return redirect("blog:list")
    ...
```

## 今天学到

- 隐藏 HTML 按钮只是界面变化，后端仍必须禁用注册入口。
- 中间件位于请求进入视图之前，适合统一拦截未登录请求。
- 中间件必须放在 `AuthenticationMiddleware` 后面，才能使用 `request.user`。
- 登录状态由 Session/Cookie 维持；未登录时 `request.user.is_authenticated` 为 False。
- Nginx 直接提供 `/media/` 时，页面登录保护不会自动保护图片直链。
- 用环境变量做功能开关，比把 `PRIVATE_SITE` 写死在代码里更容易恢复公开访问。
