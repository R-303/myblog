## 今天遇到的问题

### 1. Docker Hub 拉取镜像超时

错误：

```text
dial tcp ...:443: i/o timeout
```

处理：

- 配置 `/etc/docker/daemon.json`
- 使用腾讯云 Registry Mirror
- `hello-world` 拉取成功

### 2. Nginx 配置报 `unknown directive "\"`

原因：

```nginx
proxy_set_header X-Forwarded-Proto $scheme;\
```

行末多了反斜杠。

同时修正：

```nginx
alias /srv/myblog/media/;
```

### 3. `/healthz/` 返回 400

原因：`ALLOWED_HOSTS` 只允许公网 IP，使用 `127.0.0.1` 请求时被 Django 拒绝。

修复：

```env
DJANGO_ALLOWED_HOSTS=49.232.18.58,127.0.0.1,localhost
```

### 4. 图片全部 403

`namei -l` 显示 media 下的目录权限为 `700`，Nginx 的 `www-data` 无法进入。

修复：

```bash
sudo chmod -R a+rX /srv/myblog/media
```

### 5. 评论、投票和后台登录 CSRF 403

原因：服务器使用 HTTP，但生产配置强制 `SESSION_COOKIE_SECURE` 和 `CSRF_COOKIE_SECURE` 为 `True`，浏览器不会通过 HTTP 发送 Secure Cookie。

修复：

```python
SESSION_COOKIE_SECURE = SECURE_SSL_REDIRECT
CSRF_COOKIE_SECURE = SECURE_SSL_REDIRECT
```

这样 HTTP 试用阶段可以正常登录，未来开启 HTTPS 后 Cookie 会自动变为 Secure。

### 6. 忘记后台密码

使用 Django 管理命令重置：

```bash
docker compose exec web uv run --no-sync python manage.py changepassword R-303
```

### 7. Git push 出现 TLS 错误

错误：

```text
TLS connect error: unexpected eof while reading
```

这是网络/TLS 瞬时问题，稍后重试成功，两个提交已经推送到 GitHub。

## 今天学到

- Docker 镜像拉取失败不一定是安装错误，国内服务器常需要配置 Registry Mirror。
- Nginx 负责公网入口、静态文件和反向代理，Gunicorn 负责运行 Django。
- Docker bind mount 让 SQLite、media 和 staticfiles 持久化。
- `ALLOWED_HOSTS` 会检查请求的 Host，回环请求和公网请求需要分别配置。
- 403 不一定是账号密码错误，也可能是文件目录权限或 CSRF Cookie 配置问题。
- `namei -l` 可以逐级检查路径权限。
- `chmod -R a+rX` 是让 Web 服务器读取文件的相对安全方式。
- HTTP 试用环境不能强制 Secure Cookie；HTTPS 开启后再启用。
- 部署成功后要立即备份数据库、图片和环境变量。
