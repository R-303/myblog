## 遇到的问题

### 1. 图片地址为空

测试失败信息是：

```text
Couldn't find '/media/blog/attachments/2026/10/diagram.png'
```

响应里实际是：

```html
<img src="" alt="结构图">
```

原因是模板变量拼写错误：

```django
{{ attachment.iamge.url }}
```

正确写法：

```django
{{ attachment.image.url }}
```

Django 模板找不到变量时不会报错，而是渲染成空字符串，所以必须在响应 HTML 里检查 `src`。

### 2. 缓存不能直接缓存惰性 QuerySet

侧边栏查询原本返回 QuerySet。缓存前先把它们转成列表：

```python
"latest_posts": list(Post.published.all()[:5])
```

这样缓存里保存的是已经求值的数据，行为更明确。

## 今天学到

- `STATIC` 是代码资源，`MEDIA` 是用户上传内容。
- `ImageField` 依赖 Pillow。
- `MEDIA_ROOT` 是磁盘目录，`MEDIA_URL` 是浏览器访问前缀。
- Django 开发服务器需要通过 `static()` 临时提供 media 文件。
- 模板变量拼错通常不会报异常，只会静默渲染为空。
- LocMemCache 适合本地单进程开发，不是多进程共享缓存。
- 缓存要设置合理过期时间；本项目侧边栏最多可能延迟 60 秒更新。
