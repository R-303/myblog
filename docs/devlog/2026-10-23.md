## 遇到的问题

1. 详情页评论表单一开始没有输入框。
   - 原因：视图没有把 `CommentForm()` 放进模板上下文。
   - 修复：在 `post_detail` 中传入 `form`。
2. 评论里的 `<script>` 不能执行。
   - 处理：保留 Django 默认转义，评论不使用 `mark_safe`。
3. 提交评论刷新会重复提交。
   - 处理：POST 成功后重定向回详情页。
4. 模板 URL 名字写成了 `blog:ccomment`，报 `NoReverseMatch`。
   - 定位方法：错误里给出了 `ccomment`，全项目搜索后找到模板拼写。
   - 修复：改成 `blog:comment`。
5. 投票参数设计容易踩坑。
   - 处理：不使用容易混淆的 `0 / ±1`，改用 `like / dislike` 两个明确的字符串。

## 今天学到

- `mark_safe` 只适合可信的管理员内容，不能用于普通用户评论。
- 评论表单提交使用 POST → 保存 → 重定向，避免刷新重复提交。
- `NoReverseMatch` 先看错误里的 URL 名字，再全项目搜索，最后和 `urls.py` 的 `name=` 对照。
- Django ORM 查询使用双下划线，例如 `published_at__isnull`、`total__gt`。
- `UniqueConstraint` 可以在数据库层防止重复投票。
- `F()` 让计数在数据库里原子递增，避免并发覆盖。
- 同一 Session 只能投票一次，测试时可以用无痕窗口验证另一种票型。
